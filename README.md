# Public APIs Reference

A curated, categorized list of free and public APIs — adapted from the community-maintained [public-apis](https://github.com/public-apis/public-apis) repository.

> **Note:** Homepage/documentation links weren't available in the source data used to build this list, so the **API** column shows the service name only (not a clickable link) for most entries. The `Auth`, `HTTPS`, and `CORS` columns describe each API's access requirements.

## Example Usage

Most APIs in this list fall into two access patterns: **no authentication needed** (just call the endpoint) or **API key required** (usually passed as a query parameter or header). Below is a minimal, runnable example for each pattern using [Open-Meteo](#weather) (no auth) and [OpenWeatherMap](#weather) (apiKey auth) as stand-ins — swap the URL/key for any API in the tables above.

### 1. No-auth API — cURL

```bash
curl "https://api.open-meteo.com/v1/forecast?latitude=13.08&longitude=80.27&current_weather=true"
```

### 2. No-auth API — JavaScript (fetch)

```javascript
async function getWeather(lat, lon) {
  const url = `https://api.open-meteo.com/v1/forecast?latitude=${lat}&longitude=${lon}&current_weather=true`;

  const response = await fetch(url);
  if (!response.ok) {
    throw new Error(`Request failed: ${response.status}`);
  }

  const data = await response.json();
  return data.current_weather;
}

getWeather(13.08, 80.27)
  .then(weather => console.log(weather))
  .catch(err => console.error(err));
```

### 3. No-auth API — Python (requests)

```python
import requests

def get_weather(lat, lon):
    url = "https://api.open-meteo.com/v1/forecast"
    params = {"latitude": lat, "longitude": lon, "current_weather": "true"}

    response = requests.get(url, params=params, timeout=10)
    response.raise_for_status()

    return response.json()["current_weather"]

if __name__ == "__main__":
    print(get_weather(13.08, 80.27))
```

### 4. API-key-based service — Python (requests)

```python
import os
import requests

API_KEY = os.environ["OPENWEATHER_API_KEY"]  # never hardcode keys in source

def get_current_weather(city: str):
    url = "https://api.openweathermap.org/data/2.5/weather"
    params = {"q": city, "appid": API_KEY, "units": "metric"}

    response = requests.get(url, params=params, timeout=10)
    response.raise_for_status()

    return response.json()

print(get_current_weather("Chennai"))
```

### General tips

- **Read the `Auth` column first.** `No` means you can call it directly; `apiKey` / `OAuth` means you need to register for credentials before it will respond.
- **Check `HTTPS`.** Almost everything modern supports it — avoid the few `No` entries in production.
- **Check `CORS`.** If you're calling an API directly from browser JavaScript and `CORS` is `No`, the request will be blocked by the browser; route it through your own backend instead.
- **Respect rate limits.** Free tiers are usually capped (e.g. requests/minute or requests/month) — cache responses where you can.
- **Never commit API keys.** Use environment variables (`os.environ`, `process.env`) or a secrets manager, not hardcoded strings.
